# Flight-consolidation

Debrief system for the A320 Command Upgrade Programme line sectors.

- **`app/`** — the phone/iPad app (offline PWA, GitHub-synced). Hosted by GitHub Pages
  at `https://ltys27.github.io/Flight-consolidation/app/`. See `app/README.md`.
- **`cup-debrief/`** — the markdown + Python side: sector notes, banks, tracker,
  pre-flight cards, retrieval cards. See `cup-debrief/README.md`. The app's markdown
  export drops straight into `cup-debrief/sectors/`.
- **`BRIEF.md`** (in `cup-debrief/`) — the original design brief.
